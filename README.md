# Лабораторна робота 03

Програмування для інтернет. Форма бронювання готелю.

У формі можна вибрати номер, дати, трансфер і харчування. FastAPI перевіряє дані та зберігає заявку в SQLite.

## Запуск

Потрібен Docker з Docker Compose. У папці проєкту виконайте команду.

```sh
docker compose up --build -d
```

Відкрийте [форму бронювання](http://localhost:8003/). Щоб перевірити роботу, надішліть тестову заявку.

Щоб зупинити проєкт, виконайте `docker compose down`. Заявки залишаються в томі Docker.
